# pakistan-mosques

پاکستان کی مسجدوں کا ڈیٹا (OpenStreetMap سے)، StepTuDeen ایپ کے لیے چھوٹی tile فائلوں میں۔

- `data/index.json` — فہرست اور bbox
- `data/tiles/<y>_<x>.json` — ہر tile (0.2°) میں `[lat, lon, name]`

ڈیٹا © OpenStreetMap contributors (ODbL)۔ اپڈیٹ: Actions → Build mosque data → Run workflow۔
